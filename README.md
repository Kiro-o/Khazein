# 🛒 Khazein (خزين) - B2B E-commerce Platform

## 📱 About The Project
A comprehensive B2B order management system built from scratch to connect retail grocery stores directly with food manufacturers. The platform operates on a lean model with no dedicated warehouses or delivery fleets, charging a 2% commission from manufacturers while streamlining the supply chain.

## ✨ Key Features
* **Smart Order Routing:** Automated, atomic transaction-based logic that partitions a multi-vendor cart into isolated sub-orders.
* **Strict Data Isolation:** Enforced multi-tenant privacy at the database kernel level to protect merchant and supplier data.
* **Lean Operations:** Direct B2B connection eliminating intermediate warehousing.
* **Real-time Sync:** Instant updates for orders and inventory statuses.

## 🛠 Tech Stack
* **Frontend:** Flutter (Dart)
* **Backend:** JavaScript / Node.js
* **Database & Cloud:** Google Firebase (Firestore, Authentication, Cloud Storage)
